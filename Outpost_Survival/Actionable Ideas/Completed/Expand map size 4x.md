## Completion write-up (2026-07-20)

**Map size:** `IsoGround`'s footprint (`scenes/base/Base.tscn`) went from 28x28 (`start_x/start_y = -12`) to 56x56 (`start_x/start_y = -26`) - 4x the tile area, same center. `Base._ready()` derives `WorldGrid`'s bounds and the camera's pan/edge-scroll limits directly from `iso_ground.start_x/width`/`start_y/depth` (see `CLAUDE.md`'s Camera section), so both scale automatically with no separate change needed.

**Grove spawning:** already existed before this pass (`Base._scatter_initial_trees`, added in an earlier session) - groves were not new here. What changed is scale: `INITIAL_TREE_COUNT` (40->160), `TREE_GROVE_COUNT` (5->20), `INITIAL_ROCK_COUNT` (14->56), and `INITIAL_GRASS_COUNT` (30->120) all scaled x4 alongside the map's own 4x area increase, so ambient density per tile stays constant rather than the old counts reading as sparse on a map 4x the size. `TREE_GROVE_COUNT` scaled by the same factor as `INITIAL_TREE_COUNT` (not left fixed) specifically so `trees_per_grove` (`INITIAL_TREE_COUNT / TREE_GROVE_COUNT`) stays exactly 8 - only the number of groves visible across the map grows, not how dense/large any one grove reads. `INITIAL_TREE_RADIUS` (5.0) deliberately left unscaled - it controls one grove's own physical size, unrelated to the map's total area.

**Canopy cover:** new `WorldTree.matured` signal (`scripts/tree.gd`), emitted from the existing `_on_matured()` alongside its existing `is_mature = true` assignment. `WorldGrid.configure()` gained an optional `ground: IsoGround` param (`autoload/world_grid.gd`), stored as `iso_ground` and passed once from `Base._ready()`'s existing `WorldGrid.configure()` call. `WorldGrid.plant_tree()` connects the new signal to `_on_tree_matured()` and, for a tree planted already-mature (the initial map scatter, which never fires `matured` since that only happens via the sapling-growth tween `_ready()` starts for `is_mature=false`), calls `iso_ground.mark_canopy(cell)` immediately instead. `_on_tree_depleted()` (existing, already ran on harvest) now also calls `iso_ground.clear_canopy(cell)`.

`IsoGround` (`scripts/iso_ground.gd`) gained `_tile_atlases: Dictionary` (`Vector2i -> AtlasTexture`, populated in the existing `_place_tile()` alongside its existing `add_child(tile)` call) so a canopy toggle is an O(1) region mutation rather than a full grid rebuild, plus two new methods: `mark_canopy(cell)` (forces the tile's `AtlasTexture.region` to `WORN_REGION` - the same dirt-tile region ambient noise/clearings/paths already use) and `clear_canopy(cell)` (reverts to `WORN_REGION` if `_is_dirt(cell)` still says so - e.g. a tree planted inside an existing dirt clearing - else back to `GRASS_REGION`, so a harvested tree doesn't leave a "hole" of the wrong terrain either direction).
